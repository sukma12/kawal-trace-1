Kawal Trace 1.0 build 8 — Laporan verifikasi (29 Oktober 2026)
================================================================

BACA DULU — yang TIDAK terbukti oleh laporan ini
------------------------------------------------
* Tidak ada EXE, APK, maupun jendela Flet nyata yang dibuka di lingkungan ini (Flet/Flutter/Android SDK tidak terpasang dan paket tidak bisa diunduh).
  Karena itu klaim "area utama tidak lagi abu-abu setelah klik menu" BELUM terbukti. Yang terbukti hanya: kode dashboard asli berjalan tanpa
  exception pada tiruan Flet, semua 12 menu terpasang, dan pohon kontrol tidak lagi memuat pola tata letak yang ditolak Flutter.
* Tes "GUI" di bawah adalah tes STRUKTUR headless, bukan tes tampilan. Tidak ada piksel yang dilihat.
* Tidak ada pengujian di perangkat nyata (Windows/Android), tidak ada server/agent/SIEM sungguhan, tidak ada biometrik/notifikasi native.
* Model AI dilatih pada korpus sintetis; akurasinya pada email nyata TIDAK diukur. Database malware/phishing nyata tidak dibawa.

Lingkungan dan pengganti yang saya pakai (semuanya buatan saya, di luar paket yang dikirim)
-------------------------------------------------------------------------------------
Sandbox tidak punya pytest, httpx, websockets, flet dan tidak ada akses PyPI. Saya menulis pengganti minimal HANYA untuk menjalankan tes:
  - shim pytest (fixture, tmp_path, monkeypatch, raises, parametrize, approx, importorskip) — diperbaiki satu kali di tengah pekerjaan
    karena awalnya membuat tmp_path berbeda tiap fixture (pytest asli berbagi satu instance per tes);
  - shim httpx berbasis http.client (Client, stream, Timeout, error);
  - stub websockets: 2 tes WebSocket di test_protocol_adapters.py DILEWATI (bukan lulus).
Pengganti ini tidak ikut dalam paket. Menjalankan ulang dengan pytest/httpx/websockets asli (python -m pytest -q) tetap diperlukan; saya tidak dapat
menjamin perilakunya identik pada setiap detail. Python 3.12.3, cryptography 46.0.6, scikit-learn 1.8.0, joblib 1.5.3, Flask 3.1.3.

File tak dikenal: selama tes pertama muncul `tests/flet_stub.py` di folder kerja. File itu TIDAK ada di ZIP Anda, bukan saya yang menulisnya, dan
tidak dibuat oleh suite asli (saya mengonfirmasi dengan menjalankan suite asli pada salinan bersih ZIP). Saya memindahkannya keluar dari proyek,
tidak mengeksekusi maupun memakainya, dan menulis `tests/ui_harness.py` sendiri. Jika Anda mengenalinya, itu bukan bagian dari paket ini.

Temuan analisis (kode asli)
---------------------------
1. Layout: linter menemukan 5 pola pada tata letak build 7 yang ditolak Flutter — `expand` pada Container/Row di dalam induk non-fleksibel (SafeArea, Container),
   `Column(expand=True)` di dalam `view_host` Container, dan `Column(expand=True)` di dalam `Row(wrap=True)` pada topbar. Hipotesis saya (BUKAN fakta terverifikasi):
   ini penyebab permukaan abu-abu karena Flutter melukis kotak abu-abu untuk widget yang melempar galat. Semua pola itu dihapus di build 8.
2. Sidebar dibangun ulang pada setiap klik (kontrol yang sedang menangani klik dibuang). Diganti dengan pewarnaan di tempat.
3. Logo memakai ft.Image(src="assets/icon.png"); path ini kemungkinan keliru bila assets_dir dipakai. Diganti ikon agar tidak bergantung aset (perubahan tampilan kecil).
4. Pemindaian pola berisiko (shell=True, eval/exec, pickle, verify=False, SQL berinterpolasi, extractall, 0.0.0.0): tidak ada temuan di kode asli;
   SQL dinamis di database_audit.py/server.py memakai identifier tervalidasi/allow-list. SHA-1 hanya dipakai untuk TOTP (sesuai RFC 6238).
5. Riwayat: README/CHANGELOG mencatat gejala "panel utama abu-abu" berulang sejak build 5 dan semuanya hanya diverifikasi di level teks source. Tes kontrak lama
   memeriksa string kode, bukan perilaku — sebab itu perbaikan sebelumnya bisa "lulus" sambil gejala tetap ada. Build 8 menambah tes yang mengeksekusi kode dashboard.

Risiko kompatibilitas Flet yang tersisa
---------------------------------------
Build 8 tidak memakai tipe kontrol maupun argumen keyword Flet yang belum pernah dipakai kode asli, dan ikon baru diselesaikan lewat getattr (tidak bisa menjatuhkan dashboard).
Satu-satunya pemanggilan API Flet baru: FilePicker.pick_files (dipakai Pilih file / impor daftar / pilih backup). Tidak dapat diverifikasi di sini.
